# Guia rápido

O V0 é um RPG solo de browser com feeling de Tibia, hunts curtas, build e helper.
Phaser 4 + TypeScript + Vite; simulação determinística; save local; conteúdo Canary;
gacha somente cosmético. Produto público e multiplayer são outra fase.

Leia o [índice](README.md) para autoridade e o [roteiro](06_ROTEIRO_PLAYBOOKS_IMPLEMENTACAO.md)
para execução: PB-13 fecha o loop, PB-14 entrega variedade, PB-15 fecha dungeon e modulação.
O [diagnóstico](VALIDACAO_PROJETO.md) distingue código existente de hipóteses de produto.

A próxima task é PB-13-01. Gates seguem `AGENTS.md`; playtest é do usuário.
Não executar pendência antiga só porque uma card histórica diz que está elegível.
